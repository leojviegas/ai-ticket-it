# Bitácora de Desarrollo con IA (`ai-log`)

Este directorio almacena el registro de experimentación con herramientas de Inteligencia Artificial, sirviendo como insumo directo para la **Conclusión Final y el Video de Entrega (5 a 10 min)** del Trabajo Práctico.

## Qué registrar aquí

1. **Decisiones de Diseño Asistidas por IA**: Cómo se resolvieron casos borde no explícitos en el enunciado (ej. cálculo del puntaje del organizador, flujo de transición entre `CANCELADA` y `REEMBOLSADA`, selector de rol Comprador/Organizador).
2. **Ventajas Observadas**: En qué etapas (generación de specs, boilerplate Express, componentes React Native, tests) la IA aceleró significativamente el trabajo.
3. **Desventajas y Dificultades**: Alucinaciones, sobre-ingeniería o problemas de integración detectados y cómo el criterio técnico humano los corrigió.
4. **Evolución de Skills y Specs**: Impacto de usar `AGENTS.md`, `skills` y `specs` frente a prompts libres.
