# Architecture Decision Records (ADRs)

Esta carpeta documenta las decisiones arquitectónicas y técnicas tomadas durante el desarrollo de **AI Ticket It** (necesarias para respaldar el criterio técnico exigido por la cátedra frente al uso de IA).

## Convención de Nombres

`NNN-titulo-de-la-decision.md` (ej. `001-estructura-monorepo-y-persistencia-memoria.md`).

## Estructura Sugerida

- **Estado**: Propuesto | Aceptado | Reemplazado
- **Contexto**: Qué problema o ambigüedad del enunciado motivó la decisión.
- **Decisión**: Qué alternativa se eligió y por qué.
- **Consecuencias**: Impacto positivo y compromisos asumidos.
